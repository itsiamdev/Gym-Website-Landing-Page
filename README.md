# PowerGym Website 🏋️‍♂️💪

Welcome to the PowerGym website landing page! This is a modern, responsive website for a gym & fitness center, built with HTML, CSS, and JavaScript.

## Features 🌟

- **Responsive Design** 📱: Looks great on all devices.
- **Hero Section** 🖼️: Eye-catching header with background image.
- **Navigation** 🧭: Fixed navbar with smooth links.
- **Services** 🏃‍♀️: Sections for workouts, schedule, trainers, and pricing.
- **Trainers** 👨‍🏫👩‍🏫: Dedicated section with photos and specialties.
- **Pricing** 💰: Clear subscription plans.
- **Call to Action** 📞: Encourages sign-ups.

## Technologies Used 🛠️

- **HTML5** 📄: Structure of the website.
- **CSS3** 🎨: Styling and animations.
- **JavaScript** ⚡: Interactivity (expandable).

## File Structure 📁

- `index.html` - Main HTML file.
- `style.css` - Stylesheet for design.
- `script.js` - JavaScript for functionality.
- `images/` - Folder for trainer photos.
- `README.md` - This file.

## Live Demo 🌐

## How to Run 🚀

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Enjoy the website! 🌐
